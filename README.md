# 📚 Study Meta AI

Study Meta AI is an AI-powered learning assistant designed to help students understand academic concepts quickly and easily.

## 🚀 Features

- 🔐 Student Registration & Login
- 📊 Personalized Dashboard
- 🤖 AI-powered Question & Answer
- 📖 Exam-oriented Answers
- 📝 AI Notes Generation
- 📚 Subjects & Topics
- 🕘 Query History
- ⭐ Feedback System
- 📱 Responsive User Interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- PostgreSQL
- Gemini AI API
- Git & GitHub

## 🎯 Project Objective

The main objective of Study Meta AI is to provide students with simple, quick and exam-oriented explanations, notes and summaries using Artificial Intelligence.
